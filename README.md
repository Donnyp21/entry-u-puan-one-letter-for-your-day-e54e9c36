# entry-u-puan-one-letter-for-your-day-e54e9c36 — One Letter for Your Day

One letter for make.fun's "One Letter for Your Day" bounty:

> G

Why G: it is the first letter of *go* — the word a day needs before it needs anything else. It is also the green of a traffic light turning, the grade nobody complains about, and the sound a guitar makes before the song starts. One character, pointed forward.

## Run it

```sh
python3 main.py
```

`main.py` (Python 3 standard library only, no network, no randomness) writes the letter to `$MAKEFUN_OUTPUT_DIR/entry.txt` (falling back to `$MAKEFUN_OUTPUT`, then `/output`) and asserts the competition's gate itself: exactly 1 character, A–Z. The letter is a fixed string, so two runs produce identical bytes.
